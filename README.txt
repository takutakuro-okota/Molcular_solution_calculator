GitHub Pages 用 PWA
リポジトリ直下にこのフォルダ内のファイルを配置してください。
Settings > Pages > Deploy from a branch > main > /(root) で公開できます。
iPhoneではSafariでPages URLを開き、共有 > ホーム画面に追加 を選びます。
